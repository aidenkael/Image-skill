# Agent 多模态 QA（生成后门禁）

对每张生成图，Agent 对照参考图与 Brief 逐项目视检查。全部通过才交付；失败项做**定向**修正（只改相关 Brief/Prompt 字段）并重生成**一次**，不盲目重试。

## 商品保真（对照参考图）

| # | 检查 | 判据 |
|---|---|---|
| Q1 | 是同一个商品 | 轮廓、颜色、Logo、图案、材质、比例与参考图一致 |
| Q2 | 无凭空新增/丢失结构 | 没有多出的带/扣/口袋/按键/Logo，也没有部件消失 |
| Q3 | 未展示捏造的未知视角 | 参考图未证明的背面/底部/内部没有被编造出来 |

## 呈现与构图

| # | 检查 | 判据 |
|---|---|---|
| Q4 | 呈现形式适合商品 | 模板/场景选择合理，不是千篇一律的模板化背景 |
| Q5 | 背景不套路化 | 不是"又是同一种"默认背景；背景服务于商品而非喧宾夺主 |
| Q6 | 构图突出商品 | 商品是焦点、占比合理、不被遮挡，视线引导到商品 |

## 真实感与商业吸引力

| # | 检查 | 判据 |
|---|---|---|
| Q7 | 无明显 AI 感 | 无塑料皮肤/蜡感、假阴影、悬浮、穿模、过饱和、过度光滑 |
| Q8 | 人物自然（如出现） | 肢体/手指正常，与商品真实接触，使用方式符合物理常识 |
| Q9 | 具备电商吸引力 | 光线/氛围让人想购买，达到商业摄影水准而非"能看就行" |

## 失败处理

```
failures = [未通过的检查项]
if failures:
    只修正失败项对应的 Brief 字段 / 保真子句 / 负面 patch
    通过官方 text-to-image Skill 重生成一次
    复查；通过（或更好）则交付，否则如实报告失败项
else:
    交付
```
